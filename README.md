# FinTrack

A full-stack personal finance management platform designed to help users track income and expenses, manage budgets, set financial goals, and gain better insights into their financial habits.

## Live Demo

Visit the live application: https://fin-track-psi-three.vercel.app/

## Features

- User authentication and secure login
- Track income and expenses
- Manage monthly budgets
- Set and monitor financial goals
- Visual financial analytics and insights
- Responsive and modern user interface

## Tech Stack

### Frontend
- React
- JavaScript
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB
